Petit tour

Chaque écran du style « encre », en mode clair, sur le fond aux collines d'encre. Choisissez-en un pour l'agrandir.

  • Bureau
  • Mode nuit
  • Spotlight
  • Panneau rapide
  • Assistant IA
  • Réglages
  • Fonds d'écran
  • Thèmes
  • Pense-bête
  • Menu d'arrêt
  • Verrouillage

Pas fan de l'encre ?

Les mêmes applis existent aussi en style verre dépoli par défaut — changez le style d'interface dans Réglages → Appearance. Les couleurs suivent votre fond d'écran dans les deux cas.
