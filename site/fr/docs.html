DOC / INSTALLATION

Installation

Une ligne sur Arch Linux, une session à côté de la vôtre, rien d'écrit dans ~/.config.

Installation en une ligne

curl -fsSL https://raw.githubusercontent.com/Tataneeeeeeeeeee/Inkpaw/main/install.sh | bash

L'installeur demande avant chaque étape qui installe quelque chose ou demande sudo : fichiers, paquets, clavier, fonds d'écran, session. Ses options sont sur la page d'installation.

Comment marche la session

À chaque connexion, session/start.sh reconstruit ~/.local/share/inkpaw/session-root : des liens vers le repo pour les dossiers d'Inkpaw, des liens vers votre vrai ~/.config pour tout le reste. Il y fait pointer XDG_CONFIG_HOME, puis lance Hyprland.

L'état propre d'Inkpaw vit dans ~/.local/state/inkpaw (vos réglages, le dernier thème, les conversations, l'historique des notifications) et ~/.cache/inkpaw.

Dépannage

ProblèmeSolution
la session ne démarre paschoisissez votre session habituelle, lisez ~/.local/share/inkpaw/session.log, lancez ./test.sh verify
il manque quelque chose./test.sh deps
les notifications ignorent le thèmehypr/scripts/notifications.sh restart (un autre gestionnaire a pris la place)
mauvaise disposition de clavierRéglages → Displays → Keyboard & mouse

Pour mettre à jour, un git pull dans le repo suffit (ou relancez l'installeur). Vos réglages vivent hors du repo et survivent aux mises à jour.

DOC / CONFIGURATION

Configuration

Chaque valeur vit dans un seul fichier, chaque changement dans les Réglages est une ligne d'état — vos valeurs par défaut ne sont jamais réécrites.

Où vivent les valeurs

FichierContenu
hypr/settings.confchaque valeur : applis, clavier, écrans, espacements, bordures, polices, barre, dossier des fonds…
~/.local/state/inkpaw/toggles.confce que vous avez changé dans les Réglages — prime sur settings.conf
~/.local/state/inkpaw/theme.confle dernier thème, rétabli à la connexion
hypr/conf/keybinds/*.luales raccourcis (modificateur = MOD)
hypr/conf/custom.luavos retouches Hyprland, chargées en dernier

Le système de réglages

La fenêtre Réglages et le menu rofi sont tous deux générés depuis hypr/settings.schema, une ligne par option :

Page/Groupe | CLÉ | type | choix | libellé | apply
Bar/Layout | BAR_POSITION | choice | top,bottom | Position | bar

apply indique quoi recharger : hypr, bar, theme, mode, scheme, skin, apps… Tout est aussi scriptable :

hypr/scripts/menus/settings.sh set BAR_POSITION bottom
hypr/scripts/menus/settings.sh unset BAR_POSITION

Les modules Hyprland

hypr/hyprland.lua ne contient que des lignes require(), une par sujet dans hypr/conf/. Commentez-en une pour couper un module ; SUPER+CTRL+R recharge.

Pour afficher n'importe quelle autre clé de settings.conf dans les Réglages, ajoutez une ligne au schéma.

DOC / THÈMES

Thèmes

Choisissez un fond, et matugen en tire une palette pour chaque appli — ou choisissez l'un des neuf thèmes fixes.

Fonds d'écran et palettes

hyprtheme/theme.sh wallpaper ~/Pictures/x.jpg
hyprtheme/theme.sh static nord
hyprtheme/theme.sh mode dark
TouchesAction
SUPER+CTRL+Wsélecteur de fonds d'écran
CTRL+ALT+Tsélecteur de thèmes fixes
SUPER+CTRL+Tclair ↔ sombre

hyprtheme/generate-wallpapers.sh dessine 15 fonds avec ImageMagick. Vos propres images vont dans le même dossier.

Ajouter une appli thémée

Un fichier dans hyprtheme/templates/ dont les premières lignes disent où il va : @output: <chemin>. Utilisez {{colors.primary.default.hex}}, {{accent.a1}}, {{ansi.red}}, {{ui.font}}… et ajoutez un hook pour recharger l'appli en direct.

Le style « encre »

Réglages → Appearance → Interface style. Polices, applis et barre du haut passent en dessin à la main — panneaux parchemin, contours à l'encre, titres au pinceau et chats — tandis que couleurs, fond et fenêtres restent les vôtres.

DOC / LA BARRE

La barre

Waybar est générée à partir de quelques réglages : vous n'éditez jamais son JSON à la main.

RéglageEffet
BAR_POSITIONtop / bottom (haut / bas)
BAR_LAYOUTcenter, split, left, right, custom
BAR_STYLEcapsules, floating, solid, minimal, hyde, encre
BAR_SESSION …les modules de chaque capsule, dans l'ordre
BAR_WORKSPACES_STYLEpoints ou numéros

Sous le capot

Waybar change de bureau avec l'ancienne commande dispatch workspace N, qu'une config Lua refuse : waybar/ipc-proxy.py la réécrit en Lua. Chaque commande de clic est détachée avec setsid, pour qu'une appli ouverte depuis la barre survive à un changement de thème.

hypr/scripts/waybar.sh start|restart|reload|toggle|build
DOC / APPLIS

Applis

Spotlight, le panneau rapide, les notifications, l'assistant IA et les menus.

Spotlight

SUPER+SPACE. Une liste avec une section par type : calcul, applis, actions, fichiers, émojis, presse-papiers, web et cartes, commande. Les préfixes cherchent dans une seule section : = calcul, / fichiers, . émojis, : presse-papiers, @ web, > commande.

Panneau rapide

Cliquez sur une icône de la barre : Wi-Fi, Bluetooth, son par appli, luminosité (DDC/CI pour les écrans externes, lumière nocturne), batterie et mode d'énergie, historique des notifications, calendrier, médias. Il reste en mémoire et s'ouvre donc instantanément.

Assistant IA

SUPER+I. Une fenêtre qui se range à côté de vos fenêtres, avec des conversations (Ctrl+O, Ctrl+N), du Markdown en direct et des boutons Copier. Claude par défaut ; OpenAI, Ollama, OpenRouter ou tout point d'accès compatible dans les Réglages.

Les clés d'API sont rangées dans ~/.local/state/inkpaw/secrets.conf (droits 600), jamais dans le repo.

Raccourcis

SUPER+CTRL+SRéglages
SUPER+Iassistant IA
SUPER+Nnotifications

DOC / DÉVELOPPEMENT

Développement

Un sujet par fichier, chaque valeur dans settings.conf, les fichiers générés jamais commités.

./test.sh deps            # paquets manquants + la commande d'installation
./test.sh verify          # chaque profil d'écran, chaque fichier, chaque thème
./test.sh nested          # tout le bureau dans une fenêtre imbriquée
Pour ajouter…Faites
un réglageune ligne dans settings.conf + une dans settings.schema
une appli théméeun modèle dans hyprtheme/templates/
un thème fixeun fichier JSON dans hyprtheme/static/
un raccourciune ligne avec une description dans hypr/conf/keybinds/
un profil d'écranun fichier dans hypr/monitors/

./test.sh verify doit passer avant chaque commit — il tourne dans une copie jetable, jamais dans votre config.
