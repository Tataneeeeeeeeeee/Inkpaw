DOCS / INSTALLATION

Installation

One line on Arch Linux, a login session next to your usual one, nothing written to ~/.config.

One-line install

curl -fsSL https://raw.githubusercontent.com/Tataneeeeeeeeeee/Inkpaw/main/install.sh | bash

The installer asks before every step that installs something or needs sudo: files, packages, keyboard layout, wallpapers, login session. See the install page for its options.

How the login session works

At every login session/start.sh rebuilds ~/.local/share/inkpaw/session-root: links to the repo for Inkpaw’s folders, links to your real ~/.config for everything else. It then sets XDG_CONFIG_HOME to it and starts Hyprland.

Inkpaw’s own state lives in ~/.local/state/inkpaw (your settings, last theme, conversations, notification history) and ~/.cache/inkpaw.

Troubleshooting

ProblemFix
session does not startpick your usual session, read ~/.local/share/inkpaw/session.log, run ./test.sh verify
something is missing./test.sh deps
notifications ignore the themehypr/scripts/notifications.sh restart (another daemon took over)
wrong keyboard layoutSettings → Displays → Keyboard & mouse

Updating is a git pull in the repo (or running the installer again). Your settings live outside the repo and survive updates.

DOCS / CONFIGURATION

Configuration

Every value lives in one file, every change in Settings is a line of state — your defaults are never rewritten.

Where values live

FileWhat
hypr/settings.confevery user value: apps, keyboard, monitors, gaps, borders, fonts, bar, wallpaper folder…
~/.local/state/inkpaw/toggles.confwhat you changed in Settings — overrides settings.conf
~/.local/state/inkpaw/theme.confthe last theme, restored at login
hypr/conf/keybinds/*.luakeybindings (modifier = MOD)
hypr/conf/custom.luapersonal Hyprland tweaks, loaded last

The settings system

The Settings window and the rofi menu are both generated from hypr/settings.schema, one line per option:

Page/Group | KEY | type | choices | label | apply
Bar/Layout | BAR_POSITION | choice | top,bottom | Position | bar

apply says what to reload: hypr, bar, theme, mode, scheme, skin, apps… Everything is also scriptable:

hypr/scripts/menus/settings.sh set BAR_POSITION bottom
hypr/scripts/menus/settings.sh unset BAR_POSITION

Hyprland modules

hypr/hyprland.lua only contains require() lines, one per concern in hypr/conf/. Comment one to switch a module off; press SUPER+CTRL+R to reload.

To expose any other settings.conf key in Settings, add one line to the schema.

DOCS / THEMING

Theming

Pick a wallpaper, and matugen turns it into a palette for every app — or pick one of nine static themes.

Wallpapers and palettes

hyprtheme/theme.sh wallpaper ~/Pictures/x.jpg
hyprtheme/theme.sh static nord
hyprtheme/theme.sh mode dark
KeysAction
SUPER+CTRL+Wwallpaper selector
CTRL+ALT+Tstatic theme selector
SUPER+CTRL+Tlight ↔ dark

hyprtheme/generate-wallpapers.sh draws 15 procedural wallpapers with ImageMagick. Your own images go in the same folder.

Adding a themed app

One file in hyprtheme/templates/ whose first lines say where it goes: @output: <path>. Use {{colors.primary.default.hex}}, {{accent.a1}}, {{ansi.red}}, {{ui.font}}… and add a hook to live-reload the app.

The “encre” style

Settings → Appearance → Interface style. Fonts, apps and the top bar turn hand-drawn — parchment panels, ink outlines, brush titles and cats — while colors, wallpaper and windows stay yours.

DOCS / THE BAR

The bar

Waybar is generated from a few settings: you never edit its JSON by hand.

SettingWhat it does
BAR_POSITIONtop / bottom
BAR_LAYOUTcenter, split, left, right, custom
BAR_STYLEcapsules, floating, solid, minimal, hyde, encre
BAR_SESSION …the ordered modules of each capsule
BAR_WORKSPACES_STYLEdots or numbers

Under the hood

Waybar switches workspace with the legacy dispatch workspace N, which a Lua config rejects: waybar/ipc-proxy.py rewrites it into Lua. Every click command is detached with setsid, so an app opened from the bar survives a theme change.

hypr/scripts/waybar.sh start|restart|reload|toggle|build
DOCS / APPS

Apps

Spotlight, the quick panel, notifications, the AI assistant and the menus.

Spotlight

SUPER+SPACE. One list with a section per kind: calculator, apps, actions, files, emoji, clipboard, web and maps, command. Prefixes search one section: = calc, / files, . emoji, : clipboard, @ web, > run.

Quick panel

Click an icon of the bar: Wi-Fi, Bluetooth, sound per app, brightness (DDC/CI for external screens, night light), battery and power mode, notifications history, calendar, media. It stays in memory, so it opens at once.

AI assistant

SUPER+I. A window that docks beside your tiled windows, with conversations (Ctrl+O, Ctrl+N), streaming Markdown and Copy buttons. Claude by default; OpenAI, Ollama, OpenRouter or any compatible endpoint in Settings.

API keys are stored in ~/.local/state/inkpaw/secrets.conf (mode 600), never in the repo.

DOCS / DEVELOPMENT

Development

One concern per file, every value in settings.conf, generated files never committed.

./test.sh deps            # missing packages + the install command
./test.sh verify          # every monitor profile, every file, every theme
./test.sh nested          # the whole desktop in a nested window
To add…Do
a settinga line in settings.conf + one in settings.schema
a themed appa template in hyprtheme/templates/
a static themea JSON file in hyprtheme/static/
a keybinda line with a description in hypr/conf/keybinds/
a monitor profilea file in hypr/monitors/

./test.sh verify must pass before every commit — it runs in a throw-away copy, never in your config.
