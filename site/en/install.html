Install in one line

On Arch Linux or an Arch-based distribution with Hyprland 0.56 or newer. Inkpaw adds a session next to your usual one and never writes to ~/.config.

The command

$ curl -fsSL https://raw.githubusercontent.com/Tataneeeeeeeeeee/Inkpaw/main/install.sh | bash

Want to read it first? git clone the repo and run ./install.sh from it — same steps.

What it does — asking each time

  1. 1
    Gets the filesClones Inkpaw into ~/.local/share/inkpaw/repo, or updates it.
  2. 2
    Installs what is missingHyprland, Waybar, swaync, matugen, Walker… with yay or paru.
  3. 3
    Uses your keyboardKeeps your system layout (localectl) as your setting.
  4. 4
    Draws the wallpapers15 procedural wallpapers into ~/Pictures/wallpapers, about a minute.
  5. 5
    Adds the session“Hyprland — Inkpaw” in your login screen, with sudo.

Options

Passed after bash -s -- when piped, e.g. … | bash -s -- --yes --sddm-theme

OptionEffect
--yesanswer yes to every question
--sddm-themealso install the hand-drawn SDDM login screen
--no-depsdo not install packages
--no-wallpapersdo not draw the wallpapers
--no-sessiondo not add the login session — no sudo at all
--dir DIRclone somewhere else
--branch NAMEuse another branch

By hand

# get it
git clone https://github.com/Tataneeeeeeeeeee/Inkpaw.git ~/Inkpaw
cd ~/Inkpaw
# check, then add the session
./test.sh deps
./test.sh verify
hyprtheme/generate-wallpapers.sh
sudo ./session/install.sh --sddm-theme

You need

  • Arch Linux, or a distribution based on it
  • Hyprland 0.56+ (Lua config)
  • a login screen that reads Wayland sessions — SDDM, GDM, ly…
  • yay or paru for the AUR packages (Walker, Elephant)

./test.sh deps lists what is missing and prints the exact install command.

Changed your mind?

Remove the session and Inkpaw's own folders. Your ~/.config was never modified.

sudo ~/.local/share/inkpaw/repo/session/uninstall.sh --sddm-theme
rm -rf ~/.local/share/inkpaw ~/.local/state/inkpaw ~/.cache/inkpaw
