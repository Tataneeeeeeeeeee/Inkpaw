# Skin "encre" — ink & parchment

A hand-drawn interface: opaque parchment panels outlined in ink, uneven
corners, a hard ink shadow, brush-pen titles and a litter of original cats.
The visual source of truth is a set of design mockups, one per screen
(`Mew-*`, kept outside the repo); the comments of each file name the mockup
it follows.

Switch: `hyprtheme/skin.sh apply encre` (back: `skin.sh apply default`), or
Settings → Appearance → Interface style. What the switch writes is in
`skin.conf`; every component then reads `UI_SKIN` to load its skinned style.
The switch only changes the fonts, the look of the apps / menus and the top
bar: it keeps your colors and wallpaper (the palette below is the one of the
two encre themes, which you can pick yourself in the theme selector), your
window borders / shadows / gaps and the desktop cat setting.

night sibling works. Never put ochre text on parchment (contrast 2:1): ochre
is a FILL with ink text on it.

## Shapes

* Panels: `border: 3px solid ink`, uneven radius `16px 22px 14px 20px`
  (GTK supports 4 corners; no elliptical `/` syntax), hard shadow
  `box-shadow: 4px 4px 0 ink` (no blur). Opaque, no transparency, no blur.
* Small chips / buttons: `2.5px` (use 3px in GTK3) ink border, radius
  `10px 14px 9px 13px`. Selected / active = ochre fill + ink border.
* GTK4 apps may tilt a selected item: `transform: rotate(-1deg)` (GTK4 CSS
  supports `transform`; GTK3 / Waybar does NOT — no rotation there).
* Separators: dashed ink line (`border-bottom: 2px dashed alpha(ink, 0.35)`).
* Inputs: dashed ink border on card color.

## Fonts (bundled in `hyprtheme/fonts`, exported by FONTCONFIG_FILE)

* `{{ui.font}}` = **Shantell Sans** — body, bar, lists (weights 500–700).
* `{{ui.display_font}}` = **Caveat Brush** — titles, workspace numbers, big clock.
* `{{ui.mono_font}}` = **Courier Prime** — terminal, keys, counters.

## Cats (`cats/`, generated by `cats/build.py`, SVG + 2x PNG)

Six original cats (not game assets): `moumoute` (ginger, odd eyes),
`gribouille` (grey, third eye), `biscotte` (cream, horn), `pate` (brown,
tongue), `clafoutis` (black, stitched), `croquette` (calico, tongue).

* `head-<cat>` 120×120 face — icons, avatars, mascots
* `peek-<cat>` 120×130 face + paws — peeking over the top edge of a panel
* `sit-<cat>` 120×110 sitting — sitting on a field / card
* `sleep-<cat>` 170×92 lying, "z z" — napping on a selected card
* `paw-<cat>` 120×120 one paw — dragging a corner / hovering
* `power-{lock,logout,suspend,reboot,shutdown}` faces for the power menu

`logo/` is a link to the project's `logo/` folder (the Inkpaw mark: the
ochre cat asleep). It is used by hyprlock (top-left tile), the Settings
sidebar header, the welcome window, the SDDM theme (`session/sddm/encre/logo.png`)
and as the icon of the notifications sent by `hypr/scripts/lib.sh`.
* `gamer` (game-mode toast), `basket` (welcome window)

Path in templates: `{{ui.skin_dir}}/cats/<file>` (absolute path of this folder).
